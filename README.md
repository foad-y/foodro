# سیستم مدیریت فروشگاه

یک سیستم جامع مدیریت فروش، محصولات، کارکنان و مشتریان با React و Supabase

## ویژگی‌ها

### 🏠 صفحه اصلی (Landing)
- معرفی سیستم و امکانات
- دسترسی به صفحه ورود

### 🔐 سیستم احراز هویت
- ورود با ایمیل و رمز عبور
- محافظت از صفحات با Authentication Guard

### 👨‍💼 پنل مدیریت (Admin)
فقط برای کاربران با نقش Admin قابل دسترسی

#### مدیریت محصولات
- افزودن، ویرایش و حذف محصولات
- دسته‌بندی محصولات
- تعیین قیمت و وضعیت موجودی

#### مدیریت کارکنان
- افزودن کارمند جدید با ایجاد حساب کاربری
- تعیین نقش (Admin یا Cashier)
- ویرایش و حذف کارکنان

#### مدیریت مشتریان
- افزودن، ویرایش و حذف مشتریان
- ثبت اطلاعات تماس و آدرس

### 💰 صفحه صندوق (Cashier)
برای همه کارکنان قابل دسترسی

- نمایش محصولات به تفکیک دسته‌بندی
- افزودن محصولات به سبد خرید
- مدیریت تعداد و حذف آیتم‌ها
- انتخاب مشتری (اختیاری)
- محاسبه خودکار مبلغ کل
- ثبت سفارش

## نحوه استفاده

### 1. نصب وابستگی‌ها
\`\`\`bash
npm install
\`\`\`

### 2. راه‌اندازی پروژه
پروژه به صورت خودکار راه‌اندازی می‌شود.

### 3. ایجاد اولین کاربر Admin

برای استفاده از سیستم، ابتدا باید یک کاربر Admin ایجاد کنید:

#### گام 1: ثبت‌نام کاربر
از طریق Supabase Dashboard:
1. به بخش Authentication > Users بروید
2. یک کاربر جدید ایجاد کنید (Add User)
3. ایمیل و رمز عبور را وارد کنید

#### گام 2: ثبت اطلاعات کارمند
در Supabase SQL Editor، دستور زیر را اجرا کنید:

\`\`\`sql
-- USER_ID را با ID کاربری که ساختید جایگزین کنید
INSERT INTO employees (user_id, full_name, role, phone)
VALUES ('USER_ID', 'نام مدیر', 'admin', '09123456789');
\`\`\`

### 4. ورود به سیستم
- از صفحه اصلی، روی دکمه "ورود" کلیک کنید
- ایمیل و رمز عبور خود را وارد کنید
- به پنل مدیریت هدایت خواهید شد

## تکنولوژی‌های استفاده شده

- **React 18** - کتابخانه UI
- **TypeScript** - Type Safety
- **Vite** - Build Tool
- **React Router** - مدیریت مسیریابی
- **Supabase** - Backend و Database
- **Tailwind CSS** - استایل‌دهی
- **Lucide React** - آیکون‌ها

## امنیت

- تمام جداول دارای Row Level Security (RLS) هستند
- فقط کاربران احراز هویت شده به داده‌ها دسترسی دارند
- عملیات مدیریتی فقط برای Admin‌ها مجاز است
- رمزهای عبور به صورت امن در Supabase Auth ذخیره می‌شوند

## نقش‌ها و دسترسی‌ها

### Admin
- دسترسی کامل به پنل مدیریت
- مدیریت محصولات، کارکنان و مشتریان
- دسترسی به صفحه صندوق

### Cashier
- دسترسی فقط به صفحه صندوق
- ثبت سفارشات
- مشاهده محصولات و مشتریان
